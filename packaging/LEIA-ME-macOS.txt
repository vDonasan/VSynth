Virtual Synth para macOS
========================

1. Arraste "Virtual Synth" para a pasta Aplicativos.
2. Na primeira vez, clique com o botão direito no app > Abrir > Abrir.
   (O app não é assinado pela Apple; abrir com dois cliques mostra um aviso.)
   Se ainda assim o macOS bloquear: Ajustes do Sistema > Privacidade e
   Segurança > "Abrir Mesmo Assim".
3. Para usar guitarra ou microfone, permita o acesso ao microfone quando
   o macOS pedir.

Presets e configurações ficam em
~/Library/Application Support/Virtual Synth

Plugin para o REAPER (e outras DAWs)
------------------------------------
A pasta Plugins tem o VirtualSynth.clap e o VirtualSynth.vst3.
1. Copie o VirtualSynth.clap para ~/Library/Audio/Plug-Ins/CLAP
   e/ou o VirtualSynth.vst3 para ~/Library/Audio/Plug-Ins/VST3.
   Se o macOS bloquear, rode no Terminal:
     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/VirtualSynth.clap
2. No REAPER: Settings > Plug-ins > CLAP (ou VST) > Re-scan.
3. Numa trilha com a guitarra (entrada ligada, monitoramento ligado),
   adicione o FX "Virtual Synth". A guitarra entra pelo canal esquerdo;
   MIDI da trilha também toca o synth.
4. Para gravar as notas da guitarra como MIDI: "Saída MIDI > Enviar" =
   "Guitarra" e mande a saída MIDI do FX para outra trilha.
